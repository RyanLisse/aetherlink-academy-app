# i18n — Academy app chrome

## Choice

Tiny custom React context (`src/i18n.jsx`) + JSON catalogs (`src/i18n/en.json`, `src/i18n/nl.json`).

Why not i18next: greenfield SPA with two locales and flat keys; a ~100-line provider keeps the dependency tree unchanged and makes fallback + persistence obvious in one file.

## Behaviour

| Rule | Implementation |
| --- | --- |
| Default | `en` (`DEFAULT_LOCALE`) |
| First visit | Does **not** read `navigator.language` |
| Persist | `localStorage['academy-locale']` |
| Fallback | Missing/blank NL keys → English → key string |
| `html lang` | `document.documentElement.lang` updated from locale; `index.html` ships `lang="en"` |
| Toggle | Visible **EN \| NL** in welcome header and in-session topbar |

## Out of scope (intentionally untranslated)

- Day-pack lesson bodies, quiz questions/options, mission titles/goals/hints from the API
- Proof editor document content
- Knowledge-bank lesson titles/bodies returned by `/knowledge`
- SDLC phase labels (`Plan`…`Maintain`) kept as English tech terms in both locales
- Role names from the server (`Facilitator`, `Participant`, …)

## Adding a string

1. Add the key to **both** catalogs (English required).
2. Call `t('your.key', {var})` from a component under `I18nProvider`.
3. Prefer chrome-only keys; leave curriculum content in author language.
