# Archived parity reference

This folder preserves the fixtures and diagrams from an older optional parity
course. The repository URL now leads to the current Workshop 4 participant
starter. The old `npm run triage` commands do not exist in that starter.

Do not use this folder as a runnable assignment. Start with the current
[Workshop 4 build guide](../../workshop-4/BUILD-WITH-CLAUDE.md) and the
[sanitized n8n export](../../workshop-4/n8n-support-triage.json). Then follow
`SOLO.md` in
[`AetherLink-bv/aetherlink-day4-n8n-to-agent`](https://github.com/AetherLink-bv/aetherlink-day4-n8n-to-agent).

The archived fixtures are separate from Workshop 4's required customer
messages and transaction workbook. They remain here only as historical
reading material.
