# Atlas — fictieve onboarding-oefening

Atlas groepeert interne kennisartikelen per status. Alle data is fictief.

## Aan de slag

Vereist: Node.js 24. Geen installatie nodig.

Voer de controle uit met `npm run verify`.

## Reviewopdracht

Controleer of deze instructie overeenkomt met de beschikbare bestanden. Lees package.json, status.mjs en status.test.mjs. Maak eerst een plan. Verander tijdens de read-only missie geen bestanden.

Noem een bestandsverwijzing, je werkelijk uitgevoerde commando, de waargenomen uitkomst en een beperking. Een falend commando kan geldig bewijs zijn. Voer daarna de beschikbare test rechtstreeks met Node uit.
